- skills.sh — primary marketplace, 282+ skills, full REST API (Vercel OIDC auth), CLI `npx skills search`
- OpenAgentSkill — public REST, no auth, `POST /api/agent/resolve` does task→skill recommendation with trust scores
- agentskills.io — official spec site (Anthropic), reference only
- SkillPad — GUI wrapper for skills.sh, not programmatic
